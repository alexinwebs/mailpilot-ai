# Product design

Desktop uses a dark left rail and content canvas; mobile uses a compact header. Primary routes: Overview, Inbox, Review, Automation, Knowledge, Analytics, Audit, Accounts, Settings. Review emphasizes original message, thread context, editable reply, policy reasons, approve/reject/regenerate actions. All collections expose loading, empty and error states; status badges combine text and color. Keyboard focus, labels, semantic elements, and reduced-motion preferences are supported.
